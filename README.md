# Stranger Apps

This repository contains a Kotlin Android application scaffold for the Stranger Apps project.

## Open in Android Studio

1. Open Android Studio.
2. Select "Open" and choose this repository folder.
3. Let Gradle sync complete.
4. Choose an emulator or connected device.
5. Click Run.

## Included app ideas

- Random challenge
- Random meal picker
- Silly excuse generator
- Plant watering reminder
- Mood tracker
- Voice message mockup
- Lost item note saver

## Notes

This repo is the source code home for the Android project. The actual app run happens inside Android Studio, not from GitHub itself.
